# Raíz y Flor

Sitio estático. Un solo archivo HTML autocontenido (CSS, JS y los SVG van dentro)
más la carpeta `fotos/`.

Publicado con GitHub Pages en https://nosotros.javierforero.co

Para cambiar textos, fechas o pies de foto: buscar el bloque `const CONFIG` cerca
del inicio del `<script>` en `index.html`. Todo lo editable está ahí.
